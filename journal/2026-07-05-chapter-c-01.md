## 오늘의 에러 도감 (전부 실화)
1. **컴파일**: `did you mean 'average_ragne'?` — 함수 정의부 오타. 컴파일러의 did-you-mean은 읽으라고 있는 것
2. **컴파일 경고**: `no return statement` — deg2rad 미구현 상태. C++은 이걸 경고로만 알리고 쓰레기값을 반환한다는 걸 배움 (-Wall이 필수인 이유)
3. **링크**: `-o`를 빼먹고 `g++ ... robot_utils robot_utils.cpp` → 기존 실행 파일이 입력으로 들어가 main 중복. 재타이핑이 사고의 근원 — ↑화살표와 tasks.json으로 해결
4. **런타임**: `bool clamp_speed(...)` — double 반환값이 조용히 bool로 변환. 컴파일러는 침묵했고 **assert가 잡았다.** 테스트 먼저의 가치를 하루 만에 체감
