## 배운 문법
- **enum class / class vs struct**: 데이터 뭉치면 struct, 지킬 규칙(불변식) 있으면 class → private + 검문 메서드
- **static vs const 멤버 함수**: 멤버 변수 안 쓰면 static, 읽기만 하면 const, 쓰면 아무것도 안 붙임. next_of는 인자만 쓰므로 static
- **virtual**: 상속 여부가 아니라 "부모 타입으로 자식을 가리킬 때 어느 함수가 불리나"를 결정. C++은 기본 non-virtual(성능), Kotlin은 기본 virtual — 반대
- **왜 RobotHAL&로 받나**: ① 복사 방지 ② 다형성은 참조/포인터에서만 작동(값이면 slicing) ③ 추상 클래스는 값으로 못 받음

## 삼각함수의 정체 (드디어 이해)
- cos(θ) = 방향의 x몫, sin(θ) = 방향의 y몫. "1m 전진"을 헤딩에 따라 x/y로 쪼개는 사전
- `pose.x += v*cos(θ)*dt` = "전진거리(v·dt) × x방향 비율(cosθ)". theta 줄만 삼각함수 없음 — 방향 변화는 쪼갤 게 없으니 각도끼리 덧셈
- 곡선 데모에서 확인: theta가 매 스텝 -0.1씩(omega=(0.5-1.0)/0.5=-1.0 × 0.1), 처음엔 x만 늘다가 방향 틀며 y가 커짐
