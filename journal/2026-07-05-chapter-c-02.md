## 9번(이동 평균)에서 배운 것 — 오늘의 하이라이트
- **버그 ①**: 내부 루프 `j < i+half` — 창의 오른쪽 끝이 항상 잘림. 그런데 i=2(가장자리)에서는 경계 절단과 겹쳐 **우연히 정답**이 나왔다. "부분적으로 맞는 버그"가 제일 오래 숨는다는 걸 실감
- **버그 ②**: `int sum` — double이 조용히 절단되고(0.4→0), 나눗셈도 정수 나눗셈이 됨. **-Wall -Wextra도 이건 침묵한다** — 잡으려면 `-Wconversion` (대신 잔소리 많음)
- 8번의 `[from, to)`는 `<`가 맞고 9번의 중심 대칭 창은 `<=`가 맞다 — 루프 조건은 관례가 아니라 **구간의 정의**를 따라간다

## 8번에서 배운 것 — 경계 방어
- 방어 없는 함수에 쓰레기 입력이 오면: 범위 밖 → 사망, 빈 구간 → **NaN이 조용히 하류로 흘러감** (죽는 것보다 위험)
- 처방: 클램프 → 빈 구간 가드 → 그 다음에 계산. count를 클램프 *뒤에* 계산해야 한다는 순서 함정도 있었다
- 검증 트릭: `sector_average(scan, -5, 999) == average_range(scan)` — 전체로 클램프되면 전체 평균과 같아야 한다. 내 함수로 내 함수를 검증
