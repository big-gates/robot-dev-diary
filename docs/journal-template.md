# 일기 템플릿

주 1편, `journal/YYYY-MM-DD-chapter-X-NN.md` 형식으로 쓴다.
잘된 것보다 **막힌 것**이 본문이다 — 뒤따라오는 사람이 검색으로 도착하는 곳은 삽질 기록이다.

```markdown
# [Chapter X] 제목 — YYYY-MM-DD (Week NN)

## 이번 주 목표
-

## 한 것
- (커밋/태그 링크와 함께)

## 막힌 것 → 어떻게 풀었나 (또는 아직 못 풀었나)
- 증상:
- 시도한 것:
- 원인/해결:
- 검색 키워드(남을 위해):

## 배운 것 한 줄
> 

## 다음 주
-

## 시간 기록
- 총 N시간 (평일 N / 주말 N)
```

## 챕터 회고 템플릿 (챕터 완료 시, 태그와 함께)

```markdown
# [Chapter X] 회고 — 기간, 총 N시간

- 계획 대비: (기간·범위)
- 가장 어려웠던 것:
- 다시 한다면:
- 산출물: (코드/영상/문서 링크)
- 다음 챕터에 넘기는 질문:
```
